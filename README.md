sitegen is a faster drop-in replacement for makefun-site 1.0.0: its run(input) returns exactly the output tree makefun-site builds for a site (every page's index.html, the index and tag pages, build-report.txt and each static file), byte for byte, in a fraction of the CPU time.

## Run it

```sh
node main.ts
```
